About This Platform

Satellite Images Change Detection is an AI-powered web platform that uses the ChangeFormerV2 deep learning architecture — a hybrid Convolutional Neural Network and Transformer — to identify surface-level changes between two multi-temporal satellite images.

It also provides Explainable AI (XAI) heatmaps using gradient-weighted colormap overlays, giving you visual insight into what the model is detecting.

Model ChangeFormerV2
Framework PyTorch + Flask
